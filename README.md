# PugPort community

This is where people who use and build [PugPort](https://pugport.com) talk.
Everything happens in **[Discussions](https://github.com/pugport/community/discussions)**: sign in with
your GitHub account and start a thread.

| Category | Use it for |
| --- | --- |
| **Q&A** | "How do I…?" and "Why does it…?" questions. Mark the answer that solved it. |
| **Ideas** | Features you'd like PugPort to have. Upvote the ones you want most. |
| **Show and tell** | Your setup, the accounts and agents you combine, workflows, mods you built. |
| **General** | Anything else about PugPort. |
| **Announcements** | Releases and news from the maintainers. Comments on the dev log live here too. |

## Before you post

- Search first; your question may already have an answer.
- Include your OS, your PugPort version and which agents you use (Claude Code, Codex, Grok, Cursor, API).
- Never paste API keys, tokens, passwords or account emails, not even in screenshots.
- Be kind. Disagree with ideas, not people.

Bug reports that need tracking will move to the PugPort code repository's issues once it is public.
